UMBRELLA API Documentation Description:

Welcome to the official documentation for the UMBRELLA RESTful API. This comprehensive guide is designed to assist developers and integrators in effectively utilizing the power of our API. Our RESTful API provides a simple and efficient way to access and interact with currencies, finances, and more. Whether you're building a web application, mobile app, or integrating with other services, our API offers the tools you need to streamline your development process and unlock the full potential of your project.

In this documentation, you'll find detailed information on how to make API requests, authentication procedures, available endpoints, request/response examples, error handling, and best practices for integrating UMBRELLA into your projects.

API Version:

1.0.0

OpenApi Version:

OAS 3.1

Authorization:

You can authorize your requests using this authorization method:

  • TOKEN

TOKEN

  • The endpoints are authorized using a TOKEN.
  • To authorize requests, please add a Token using the 'Authorize' button with the following format: 
    • "Bearer user-token"
